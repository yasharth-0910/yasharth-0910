## Selected work

| Project | What it is | Stack |
| --- | --- | --- |
| [Pragya](https://github.com/yasharth-0910/pragya) | RAG platform that answers employee questions from company documents and cites the exact file and page. Hybrid search with a reranker, and department-level access enforced in the vector database. | Python, FastAPI, Next.js, Qdrant, PostgreSQL |
| [SahYatri](https://github.com/yasharth-0910/SahYatri) · [live](https://sahyatri.yasharth.xyz/bus/) | Bus occupancy tracker. A Raspberry Pi camera counts passengers with YOLO and sends counts and location to a web dashboard and a mobile app. First prize at BITBOX 5.0 (GDG JIIT-128). | Raspberry Pi, YOLO, FastAPI, Node.js, PostgreSQL, Next.js, Flutter |
| [RenderLab](https://github.com/yasharth-0910/Render-Lab) · [live](https://renderlab-wine.vercel.app) | Software rasterizer that runs in the browser with no WebGL. Interactive labs for Bresenham lines, back-face culling, alpha compositing and line simplification. Course project, built with a classmate. | TypeScript, React, Canvas |
| [SciSort](https://github.com/yasharth-0910/SciSort) | Classifies arXiv CS papers into six subfields from title and abstract. Compares a TF-IDF and logistic regression baseline with a fine-tuned DistilBERT on the same held-out test set. | Python, scikit-learn, PyTorch, Hugging Face |
| [Algo-Benchmaker](https://github.com/yasharth-0910/Algo-Benchmaker) | Desktop tool to visualize and benchmark pathfinding (A*, Dijkstra, BFS, DFS, greedy best-first, JPS) on ASCII or PNG mazes. Made for robot navigation work at CICR. | C++17, SFML, CMake |
| [UniID](https://github.com/yasharth-0910/UniID) · [live](https://uniid.yasharth.xyz) | Campus ID system where one RFID card handles attendance, access control and payments. The card only holds a UID and all the rules live on the server. Built for Innovate 3.0. | Next.js, TypeScript, PostgreSQL |
